#​ ​👩‍💻 To Do List com React - Raquel Negrão

> Seu planejador de tarefas leve e funcional — feito em React!

###  Sobre o projeto
  - Este repositório contém um app de lista de tarefas desenvolvido com **React**;
  - Treinamento de hooks, estado, interatividade e boas práticas em frontend.

---

##  ⚙️ Funcionalidades
-  **Adicionar** tarefas via formulário com validação básica.
-  **Marcar como concluída** e remover tarefas com estilo.
-  **Filtros inteligentes**: mostrar todas, apenas concluídas ou só pendentes.
-  **Busca dinâmica**: filtro em tempo real conforme você digita.
-  Contador de tarefas **ativas** e **concluídas** atualizado automaticamente.

---

##  🔧 Tecnologias usadas
| Tecnologia | Utilização |
|------------|------------|
| React      | Base do app e gerenciamento de estado (useState) |
| CSS        | Estilização simples e responsiva |
| JavaScript | Lógica do projeto e manipulação de dados |
